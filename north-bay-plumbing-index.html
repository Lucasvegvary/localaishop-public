How accurate this is

Accurate against the named public source as of November 6, 2026: fewer than 1 published fact in 1,000 differs from the state's license file (95% confidence).

How that was checked, on November 7, 2026. The release is 5,250 facts: 7 facts for each of the 750 licenses (status, years licensed, number of license classes, workers' comp wording, business type, disciplinary bond, pending action). Every number on this page is computed from those 5,250 facts and nothing else. A program written independently of the Index, from the fact definitions and the state's file layout alone, rebuilt all 5,250 facts from the state's file. Then 2,995 of the facts were drawn at random, one by one, and compared: 0 differed. At least 299 facts of each of the 7 kinds were drawn, and each kind had 0 wrong. Before that, 50 errors were planted in a copy of the release; the checking program caught all 50. The draw was written down before it ran (seed, file fingerprints, pass line) and was run once. 0 wrong among 2,995 random draws means that, with 95% confidence, fewer than 0.1% of the published facts differ from the state's file.

What this does not say: whether the state's bulk file matches the state's own license-lookup page on the same day; anything about a shop's website, reviews, answering or hiring (none of those are in this release); whether any license holder actually has employees.

Method and definitions

Source: the License Master file from the CSLB public data portal, downloaded November 6, 2026 at 9:47 AM Pacific, saved and fingerprinted (SHA-256 of its contents 41b34dbd6fd4664be9aff0bf1cf1b3ad3d1afdc50f7eed72f651e33c73ac6232). A license is in this Index when the file lists its county as Sonoma, Marin, Solano or Napa and its classes include C-36. Each fact, in the state file's own column names:

In clear standing
PrimaryStatus is CLEAR and SecondaryStatus is blank.
Years since first licensed
Days from IssueDate (ReissueDate when IssueDate is blank) to November 6, 2026, divided by 365.25.
License classes
The count of classes in Classifications(s).
Workers' comp cover
The state's own WorkersCompCoverageType words, shown as the state writes them. "Listed" = any wording except Exempt, "License does not have current W/C", or blank.
Business type
BusinessType as the state writes it.
Disciplinary bond on file
DBNumber is not blank.
Suspension or class removal pending
Any of PendingSuspension, PendingClassRemoval, PendingClassReplace is not blank.
